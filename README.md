# Proyecto-Movilidad-Urbana-y-Productividad-Económica
Contexto: El objetivo fue analizar si existe relación entre la congestión urbana y el PIB per cápita de distintas ciudades.

Problema: Determinar si ciudades con mayor productividad económica presentan también mayores niveles de congestión.

Herramientas utilizadas: Python, Pandas, Jupiter

Conclusiones: Se identificaron diferencias significativas entre ciudades. / No se observó una relación lineal fuerte entre PIB per cápita y congestión. / Otros factores pueden influir: infraestructura, transporte y densidad poblacional.
